# v2.0.0

Draft release notes. `v2.0.0` is not tagged yet.
Every change below is in the `v1.0.0..v2.0.0` range and names the issue and
commit that made it.

## Summary

- The module path is now `github.com/alexgorbatchev/go-tui-frame/v2`. Callers
  that require `v1.x` keep building unchanged; move to v2 by changing the
  import path.
- Keys reach the child exactly as the outer terminal sends them. Capture no
  longer widens the outer keyboard protocol, so a legacy child's Ctrl+digit,
  Ctrl+I and Ctrl+M arrive in their legacy forms.
- Observers get stronger guarantees: `Exited` follows `Started` exactly once,
  observer panics and `runtime.Goexit` end the session cleanly, and
  `Terminal.Cells` and `Terminal.Native.Cells` share one grid.
- Native cells index a per-snapshot style table instead of each holding a
  full libghostty style, which shrinks them from 96 to 24 bytes. The table
  holds at most one style per cell plus the default style, so a snapshot in
  which every cell has its own style grows by at most that one 72-byte style.
- The module ships its native build contract, `scripts/native.sh` and
  `scripts/with-libghostty-cppflags`, for consumers to build libghostty with.
- `tui-frame` returns the child's own status after Ctrl+Q, cancels on SIGHUP,
  and moves its demo controls behind a Ctrl+B prefix.

## Breaking changes

- **Module path** (#117, `c71641c`). `go.mod` declares
  `github.com/alexgorbatchev/go-tui-frame/v2`, as Go's
  [major version suffix rule](https://go.dev/ref/mod#major-version-suffixes)
  requires. Install it with
  `go get github.com/alexgorbatchev/go-tui-frame/v2` and import
  `frame "github.com/alexgorbatchev/go-tui-frame/v2"`.
- **Capture sees keys in the child's protocol** (#107, `77616cf`). The outer
  terminal runs exactly the child's Kitty flags and modifyOtherKeys level, and
  passed keys reach the child as their raw bytes; the frame no longer decodes
  and re-encodes keys. With a legacy child, a `Capture` handler gets Ctrl+digit
  as the digit or control character a legacy terminal sends, Ctrl+I as Tab,
  Ctrl+M as Enter and Ctrl+[ as Escape. A child that enables Kitty
  disambiguation or modifyOtherKeys mode 2 makes them distinct. While the
  outer terminal has not reported Kitty keyboard support, the child's Kitty
  keyboard query gets no reply and emits no `Protocol` event.
- **Native cell styles** (#33, `f12ffd9`, `e335b99`). `NativeCell.Style` is replaced
  by `NativeCell.StyleIndex`, an index into `NativeState.NativeStyles`, the
  snapshot's style table, which holds each style once. A native cell is 24
  bytes instead of 96, and each style in the table adds 72 bytes. The table
  holds at most one style per cell plus the default style, so snapshot copies
  and their observation weight shrink with every style that cells share; when
  every cell has its own style, as in a gradient, they stay at 96 bytes per
  cell plus one style. Migrate `cell.Style.X()` to
  `state.NativeStyles[cell.StyleIndex].X()`, with the `NativeState` of the
  snapshot that holds the cell: an index is meaningful only with its own
  snapshot's table. `Wide` keeps its `ghostty.CellWide` type, and the field
  order changes, so unkeyed `NativeCell` literals need field names.
- **Shared cell grid** (#2, `d5df2fa`). Within one snapshot,
  `Terminal.Cells` and `Terminal.Native.Cells` are the same storage, so an
  edit to either shows in both. Separate snapshots still own their cells.
- **Indexed palette colors in snapshots** (#13, `481578e`). On a 256-color
  outer terminal, a cell color that uses an inherited palette entry the child
  has not redefined is an `ansi.BasicColor` (entries 0-15) or
  `ansi.IndexedColor` instead of resolved RGB; a 16-color terminal does this
  for entries 0-15. The RGB is in `Terminal.Native.Colors.Palette`. True-color
  and colorless terminals keep resolved RGB.
- **Ultraviolet fork** (#16 `fd80d16`, #96 `799ff7e`). This module's `go.mod`
  replaces `github.com/charmbracelet/ultraviolet` with the
  `alexgorbatchev/ultraviolet` fork, which keeps a Kitty report's alternate
  keys apart from its text and leaves lock state out of `MatchString`. Go
  applies `replace` only in the main module, so consumers add the same
  directive to their `go.mod`; the README gives it.

## Library behavior changes

### Observation

- **`NativeState.MouseTrackingMode`** (#91, `26790f3`). New field: the
  child's active mouse tracking mode (9, 1000, 1002, 1003 or none), from
  libghostty's mouse encoder. `MouseTracking` stays the getter's value, true
  while any tracking mode bit is set.
- **`Exited` is guaranteed** (#100, `d441626`, `865c077`). `Exited` follows
  `Started` exactly once before `Run` returns, including when cleanup rather
  than the session loop reaps the launch leader. An `Exited` that overflows
  the queue is reported as `ErrObservationOverflow`.
- **Observer panics and `runtime.Goexit`** (#57 `9c338b3`, #88 `184c362`,
  #103 `59b5a00`). A callback panic, `panic(nil)` or `runtime.Goexit` ends the
  session as cancellation does, restoring the terminal and cleaning up the
  child; `Run` returns an error with the panic value or a `runtime.Goexit`
  note, and the stack.
- **A lone large observation is admitted** (#9, `c361970`). An event that
  arrives while nothing is waiting or executing is admitted at any weight, so
  a snapshot over the 16 MiB budget no longer fails `Run` at startup.
- **Unroutable input is withheld, not fatal** (#19, `70ddb4c`, `03c2edf`). A
  mouse event the child's encoding cannot represent is withheld and the
  session continues. Observers get a `Routed` event with `Origin`
  `unroutable-input` and the reason in `Event.Error`.
- **Process sampling** (#1, `e719c84`). A redraw caused only by scrolling
  reuses the previous process sample until it is 250 ms old.
- **Synchronized-update checkpoints** (#12, `e9fc4fa`). A held frame's cells
  are copied only when a paint or snapshot shows them.

### Run and cancellation

- **Cancellation cause** (#99, `0779602`). `Run` returns
  `context.Cause(ctx)` for an already-canceled context.
- **Termination** (#92 `4e5a8db`, #97 `76e45c7`, #93 `0070889`, #29
  `8d99eb9`, `c58f43a`). The session drains the child PTY until cleanup reaps
  the killed child. If the launch leader has not exited two seconds after
  SIGKILL, the session closes the child PTY, discarding unread output, and
  waits for the leader. A Darwin process group whose members have all exited
  counts as gone. SIGTERM and SIGCONT go to the groups of one enumeration and
  each SIGKILL to a fresh one; an enumeration that fails partway still
  signals the groups it found.
- **Input backpressure** (#6, `27c863d`). Beyond 1 MiB of routed input
  waiting for a child that is not reading, the frame stops reading the outer
  terminal until the child reads again, instead of ending the session.
- **Repaint pacing** (#15, `a69cc7f`). Application invalidations and outer
  input follow the 17 ms repaint deadline.
- **Startup resize** (#59, `6352e22`). The session subscribes to SIGWINCH
  before reading the outer size, so a resize during startup is not lost.

### Outer terminal handling

- **Startup probe ends at DA1** (#22, `4b5352e`, `526269c`). The startup
  queries end with a DA1 query whose reply ends the probe; 300 ms remains the
  limit for a terminal that answers neither DA1 nor every other query. The
  probe still waits for the alternate-screen report.
- **Switchable alternate screen required** (#85, `4127efc`). Startup rejects
  a terminal that reports mode 1049 as permanently set, permanently reset or
  not recognized.
- **Permanent DEC modes** (#23, `d1f2461`, `0ff21c8`, `1a66cb2`). The frame
  never switches a mode the terminal reports as permanent, requests no mouse
  reports a permanent 1016 makes unreadable, and drops pixel mouse reports
  that arrive before the cell size is known.
- **Cursor** (#21, `f67190e`, `1435a22`). The session writes the outer cursor
  style or color only where the child's differs from what the terminal
  reported, and resets a changed attribute to the terminal's defaults with
  `CSI 0 SP q` or `OSC 112`.
- **Mouse modes** (#91 `26790f3`, #111 `04cd556`, #17 `a27695d`, #83
  `a7e782b`, `b3c45c7`). The outer terminal mirrors the child's active
  tracking mode; each exclusive mode group is written resets first; alternate
  scroll (mode 1007) applies only while the child is on its alternate screen
  without tracking; an X10 release releases every button the child holds.
- **Late Kitty support** (#58, `d5019b3`). A Kitty reply after the startup
  probe pushes the keyboard entry, so restore clears it.
- **Width rule** (#86, `564b54d`). The child starts with, and resets to, the
  outer screen's grapheme width rule; inherited mode 2027 no longer overrides
  it.
- **Replies and paste** (#18 `bb1768b`, `4b78379`; #20 `8d19897`; #7
  `c1ef995`). Bracketed-paste payloads reach the child unchanged, even when
  shaped like a reply; every outer cell-size reply is consumed instead of
  forwarded; reply parsing no longer truncates later OSC 8 hyperlinks.
- **Capture release pairing** (#53, `b2a6a03`). A passed press's repeats and
  release follow the press's disposition.
- **Child environment** (#55, `2e3ab8f`, `1046cf7`). The frame removes
  outer-terminal variables that misdescribe the child's endpoint, such as
  `TERM_PROGRAM`, `KITTY_WINDOW_ID`, `GHOSTTY_RESOURCES_DIR`, `WT_SESSION`,
  `COLUMNS` and `LINES`, with their version variables. The README lists them
  all.

## Building consumers

- **`scripts/native.sh`** (#25, `12bf062`). The module ships the native build
  contract: Ghostty revision, archive checksum, Zig version and build flags.
  Consumers run the copy in the module version their `go.mod` selects.
- **`scripts/with-libghostty-cppflags`** (#105, `756c43d`, `efb3e0e`). Run cgo
  builds through it so Go's build cache keys the libghostty binding by its
  native prefix and archive SHA-256.

## tui-frame CLI

- **Ctrl+B prefix** (#107, `aadc3c5`, `c0c28e4`). Demo actions are Ctrl+B
  then 1, 2 or 3; Ctrl+B twice sends one Ctrl+B to the child; Ctrl+Q quits,
  also after the prefix.
- **Exit status after Ctrl+Q** (#95 `0f4ad01`, #80 `5ef198d`). Ctrl+Q returns
  however the child ends: 143 when SIGTERM ends it, 137 after SIGKILL, or the
  child's own code; a Ctrl+Q after the child already exited returns that
  exit's status. A session failure after Ctrl+Q is reported with a nonzero
  status.
- **Signals** (#24, `e661c4f`, `3be49c5`). SIGHUP, SIGINT and SIGTERM cancel
  the session and return `128 + signal number`.
- **Child exit statuses** (#82, `9627149`). A nonzero child exit returns its
  status without an error diagnostic.
- **Footer** (#28, `8218b17`). Key hints stay on their own row below long
  child titles.
